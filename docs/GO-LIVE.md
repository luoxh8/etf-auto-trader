# 落地指引：两条路，选一条

> 这个仓库（CLI + 策略 + 风控）已经建好并自测完成。剩下的是**让你真的能用上自动化**，
> 这需要你本人操作——下面两条路都需要你的账号，我无法代办。
> 两条路的**参数建议都来自本项目模拟器的实测**（见 `docs/COSTS.md`）。

---

## 先说结论：你要的是哪条

你说的是「**登录国元点金**，然后就能自动交易」。这里有个关键事实：

| | 路 A：国元点金 App 自带条件单/网格 | 路 B：本仓库 CLI + 国元远航 PC 端 |
|---|---|---|
| 需要装什么 | **什么都不用装**（你已经在用） | 装国元远航 PC 客户端 |
| 用什么登录 | **国元点金账号**（就是你说的那个） | 国元远航 PC 客户端账号 |
| 自动化在哪跑 | **券商服务器**（关手机也生效） | 你自己的电脑（电脑要开着） |
| 策略自由度 | 低（网格/止盈止损/条件触发） | 高（可写任意策略，AI 可驱动） |
| 成本 | 免费 | 免费（但要锁客户端版本） |
| 稳定性 | **稳**（官方功能） | 脆（GUI 自动化，客户端升级可能失效） |
| 风险 | 无协议风险 | 可能违反券商协议 |

**如果你想"登录一下就能自动交易"，路 A 更快、更稳、且是官方支持的。**
**如果你要"让 AI 按自定义策略驱动"，只能是路 B。**

两条路不冲突，可以先用 A 跑起来，再用 B 做进阶。

## 路 A：国元点金 App 的条件单 / 网格（推荐先试）

### 依据（已核实）

国元证券官网《条件单功能使用说明》原文（`gyzq.com.cn/a/20220401/65136172.html`）：

- 「全自动条件单按用户设定的条件自动监控行情走势，**无论用户是否登录终端**，当预设条件触发时，
  系统按照预设的委托方向、价格、金额/数量**自动提交委托订单到柜台**」
- 「一个条件单（网格交易除外）在有效期内**仅会触发一次**……**网格交易只要还在有效期内，
  会根据网格策略继续监控**」
- 「条件单目前支持沪深 A 股（含科创板和创业板）、**场内交易型基金**、可转债、国债逆回购等」
- 括注：「**网格交易（国元远航客户端暂不支持）**」→ **网格只能在手机上设**

### 操作步骤

1. 打开**国元点金 App** → 交易 → 找「**智能交易**」或「**条件单**」（不同版本菜单名可能不同）。
2. 选「**网格交易**」（或叫「网格条件单」）。
3. **先用本项目算出表单要填的数字**（App 表单通常要「区间上限 / 下限 / 格数」）：

   ```powershell
   # 把 <现价> 换成 513050 的当前价格
   .venv\Scripts\python.exe -m etfa grid appform --base <现价> --spacing 3 --qty 2800
   ```

   以 **2026-10-16 收盘价 1.011** 为例，输出是：

   | App 表单字段 | 填 |
   |---|---|
   | 区间上限 | **1.138** |
   | 区间下限 | **0.895** |
   | 网格数量 | **8** |
   | 每格数量 | **2800 份**（约 2500~3200 元/格） |

4. **⚠ 注意一个真实差异**：上面的数字用**等比**间距（每格固定 3%），
   而券商 App 的网格表单通常按**等差**（每格固定价差）计算。实测同一区间下
   两条阶梯最多差 **0.006 元 = 6 个最小变动单位**：

   ```
   等比（本项目）: 0.895 0.923 0.951 0.981 1.011 1.041 1.073 1.105 1.138
   等差（App）  : 0.895 0.925 0.956 0.986 1.016 1.047 1.077 1.108 1.138
                    ↑ 中间几格错开最多 6 个 tick
   ```

   **含义**：**不要在同一个账户上同时手工挂等比单 + 让 App 跑等差网格**，两边会下重叠的单。
   选一套。`appform` 的输出里有 `ladders` 字段可逐格核对。

5. **记下到期日**：条件单最长 30 个自然日，到期自动失效 → **在手机日历上设个提醒**。
6. **退出 App 验证**：设置完成后彻底退出国元点金，观察条件触发时是否仍会成交
   （官方说明是「无论用户是否登录终端」都会提交，但**值得你自己确认一次**——
   这是"登录一下就能自动交易"是否成立的关键证据）。

### 注意

- **ETF 佣金**：先确认国元给你的 ETF 佣金率，并问「**有没有最低 5 元**」。
  模拟实测：同一路径、同一笔交易，有最低 5 元时净 +166.08，**免 5 时净 +229.50（多 38%）**。
  → **打 95578 谈掉最低 5 元，比调任何参数都值钱。**
- **溢价率**：513050 是 QDII，历史限购时场内价可能大幅高于净值（IOPV）。
  交易时看 IOPV，**溢价率超过 2% 就谨慎或降低网格金额**。
- **单边行情**：模拟实测网格在单边下跌里亏 **1237 元**（−1.77%）。这是网格的本性。

## 路 B：本仓库 CLI（需要装 PC 客户端）

### 三步

1. **打 95578** 问：「我的账户能否用**国元远航（同花顺版 PC 客户端）**登录交易？」
   （早年国元曾以「登记委托来源」为由不支持第三方客户端，现状以客服口径为准。）

2. **装客户端并手动登录**：
   - 从国元官网 → 网厅 → 软件下载 → **电脑客户端下载** → 「国元远航版PC客户端」
     （`gyzq.com.cn/main/wangting/software_download/index.html`）
   - **手动登录你的国元账号，保持窗口开着**（这就是「登录一次」的意思——
     程序不存任何密码，它附着在你已登录的客户端上）
   - 装完**锁定这个版本**（备份安装包、关掉自动更新）：GUI 自动化对客户端版本敏感

3. **一键接线 + 验证**：

   ```powershell
   cd D:\codex_proj\dev\projects\etf-auto-trader
   powershell -NoProfile -ExecutionPolicy Bypass -File scripts\onboard.ps1
   ```

   它会自动找到 `xiadan.exe`、写进配置，然后依次跑 `doctor` → `status --connect` → `probe`。

   **看 `probe` 的输出**，两个字段：
   - `verdict.compatible: true` → 兼容，可以用
   - `window.title_source` **不能是 `easytrader default`**（那说明窗口标题没固定住，
     而 easytrader 连接时会关掉标题不匹配的主窗口——见下面「已知陷阱」）

### 然后

```powershell
# 先干跑，看策略想做什么（绝不下单）
.venv\Scripts\python.exe -m etfa plan grid --code 513050 --base <现价> --spacing 3 --qty 2800

# 确认无误再真下单，金额要小
.venv\Scripts\python.exe -m etfa buy 513050 --qty 100 --reason "首次实盘验证"
```

## 已知陷阱（本仓库已修复，但你要知道）

这些都是我在开发中**实测发现并修掉**的真缺陷——如果你绕过本仓库手工操作，或遇到异常，可以对号入座：

| 陷阱 | 症状 | 状态 |
|---|---|---|
| easytrader 连接时关掉主窗口 | 一 connect 你的交易窗口就没了 | 已修（先固定窗口标题）；`probe` 的 `title_source` 可核查 |
| 撤单匹配字段错 | 撤单永远说"找不到该委托" | 已修（用 `合同编号` 而非 `委托编号`） |
| 网格只交易一次 | 开了网格却几乎不成交 | 已修（锁存器会自动解锁） |
| 做 T 腿卡死 | 卖出一笔后整天不再动 | 已修（加了时间止损 + 价格止损） |
| 被拒单污染策略状态 | 网格以为持有没买到的份额，之后卡死 | 已修（拒单回滚状态） |
| `doctor` 不校验 exe_path | 路径打错字仍报"就绪" | 已修（改为校验文件存在） |
