## 三、本仓库改过什么（**13 个真实缺陷，勿重蹈**）

这些都是**开发中实测发现并修掉**的。若有人重造轮子，会全部重踩一遍。

### A. 会让**功能静默失效**（不报错，最难查）

| # | 缺陷 | 症状 | 已修 |
|---|---|---|---|
| 1 | **`connect()` 会关掉客户端主窗口** | easytrader 的 `_close_prompt_windows()` 关闭所有标题≠`网上股票交易系统5.0` 的 `#32770` 窗口，而同花顺**主窗口正是 `#32770`** → 一 connect 窗口就没了 | `cd98630`：附着前先探测并固定窗口标题 |
| 2 | **防关窗口的函数从来没生效** | 上条修好后，探测函数 `import psutil`（**不是本项目依赖**）→ 导入失败被宽 `except` 吞 → 永远返回 None → 保护形同虚设 | `1adc1b0`：改纯 pywin32；加 AST 测试禁止未声明依赖 |
| 3 | **撤单永远匹配不到** | easytrader 按 `config.CANCEL_ENTRUST_ENTRUST_FIELD` 匹配，通用 `ths` 是 **`合同编号`** 而非「委托编号」→ 我暴露的 id 永远对不上 | `bd9ab62`：运行时读该字段名并用它作 id |
| 4 | **网格只交易一次** | `state` 把档位永久标"已完成" → 第一笔后网格就死了 | `6b7c5d4`：改成**自动解锁的锁存器** |
| 5 | **做 T 的腿永久卡住** | 反T 卖出后价格一路涨，买回价永远等不到 → 当天不再交易（**文档里警告过"要设时间止损"，代码里没实现**） | `6243c8f`：加**时间止损 `max_leg_ticks`** + 价格止损 `stop_loss_pct` |
| 6 | **被拒的单会污染策略状态** | 策略在 `plan()` 乐观锁存，被风控拒绝后 CLI 仍持久化 → 网格以为持有没买到的份额 → 之后去卖不存在的股票 → 永久卡死 | `c921e78`：`strategy_tick()` 未被接受的意图**回滚快照** |

## 四、业务结论（用模拟器实测出来的，直接可用）

`etfa simulate` 用**真实策略 + 真实风控 + 真实费率**跑合成行情。**513050、5 万本金、480 tick**：

| 场景 | 间距 | 净收益 | 手续费占毛利 |
|---|---|---|---|
| 震荡 | **3.0%** | **+166.08** | 30.2% |
| 震荡 | **1.5%** | **−8.04** | **103.4%** ← 必亏 |
| 上涨 | 3.0% | +1700.97 | 8.0% |
| 下跌 | 3.0% | **−1237.06** | 15.8% |
| 震荡（**免5**） | 3.0% | **+229.50** | 3.5% |

**三条可决策结论**：
1. **网格间距别小于 2%**，推荐 3%（1.5% 实测必亏）。
2. **「免5」值 63 元（+38%）** —— **谈佣金比调参数更值钱**。
3. **网格在单边下跌里亏钱是本性**（−1237 元）。

**做 T 对比网格**（震荡市）：做 T 净 +126.87（手续费占毛利 **47%**）vs 网格 +166.08（30%）→ **做 T 摩擦更重**。


**配置要点**（`config/config.json`）：
```json
{
  "broker": {
    "type": "easytrader_ths",
    "clienttype": "universal_client",   // 通用同花顺（用户正是这种），而非 "ths"
    "user": "你的资金账号",
    "exe_path": "D:\\tools\\ths\\<目录>\\xiadan.exe"
  }
}
```
`universal_client` 需要密码，**只从环境变量读**（`ETFA_BROKER_PASSWORD`），**永不落盘**。

## 六、别踩这些（本机环境事实）

- **pip 默认走清华镜像，而清华镜像没有 easytrader** → 装它必须 `-i https://pypi.org/simple`。
- **本机 Python 由 uv 托管（PEP 668 externally-managed）** → 不能直接 pip 装，项目必须独立 venv（已在 `.venv`）。
- **pywinauto 元数据漏声明 `pywin32`** → `[live]` extra 已手动补。
- **`psutil` 有意不引入** → 有 AST 测试禁止未声明依赖，别再加。
- **PowerShell 内联命令在本机（cmd 承载）经常静默失败**：`$变量` 被提前展开、中文乱码、错误进 stderr 被吞。**改用 Python 脚本**（`.py` + 直接 `python.exe`）或写成 `.ps1` 文件用 `-File` 调用。**本轮实测：Python 一次成功、PowerShell 内联反复失败。**
- **UTF-8 区域编码会损坏文件名** → 目录名可能出现 `U+FFFD`。用户已关闭该设置。
- 改规则只改 `ai-bootstrap\AGENTS.md` 正本。
